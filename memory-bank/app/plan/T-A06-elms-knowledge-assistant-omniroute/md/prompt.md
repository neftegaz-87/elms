## Epic

### Outcome
Сотрудник Desk может спросить про существующие API и DocType ELMS и получить проверяемый ответ, а администратор включает эту возможность в отдельном окне настроек интеграций. Без настройки ассистент честно недоступен, остальное обучение работает.

### In
- отдельное окно настроек интеграции LLM/OmniRoute;
- кнопка ассистента рядом с поиском по связям в кабинете обучения;
- grounded-ответы только из as-built индекса методов и схем;
- выбор модели из живого списка прокси и локальная история в браузере.

### Out
RAG, обучающий чат для слушателя, плавающая глобальная кнопка, серверный архив переписки, обязательный LLM в прод-контуре, выгрузка OpenAPI как главная цель.

### Done when
1. Admin сохраняет интеграцию в отдельной Form Settings и staff открывает ассистента из панели поиска по связям.
2. Ответ ссылается на реальные method/DocType; выключенная или битая интеграция даёт явную ошибку, а LMS-функции продолжают работать.

### Forbidden after
Двойной путь конфигурации (форма и параллельный site_config fallback), ответ «из общих знаний» без источников, floating FAB вместо кнопки у поиска, зависимость основного продукта от зарубежного LLM.

### Chat decisions
- Persona: Desk staff, не Learner.
- Entry: кнопка в интерфейсе «Поиск по связям», не floating.
- Optional OmniRoute fail-closed.
- Corpus: DocType JSON + whitelist + REST cheat sheet.
- Settings: отдельный Single «настройки интеграций» как в CRM/ERP.
- Поля: enabled, base_url, Password key, default_model.
- Write настроек: Admin + System Manager.
- Model picker + default luna-high; history в sessionStorage.

## Board

title: Ассистент знаний ELMS и настройки интеграций

summary: |
  Что делаем
  Добавляем в ELMS отдельное окно настроек интеграций и чат-помощника для сотрудников Desk: можно спросить, какие методы и документы есть в системе, и получить ответ с проверяемыми источниками.
  Зачем это бизнесу
  Методисты и админы быстрее находят правильный контракт API без выдуманных эндпоинтов; подключение ИИ остаётся выключаемым и не ломает работу СДО без внешнего сервиса.
  Стадии
  1) Окно настроек OmniRoute и серверный клиент.
  2) Сборка as-built контекста и API чата.
  3) Кнопка у поиска по связям, панель чата и mixed QA.
  Результат для наблюдателя
  В Settings открывается форма интеграций, в кабинете обучения рядом с поиском есть ассистент, а при выключенной интеграции обучение продолжает работать.
