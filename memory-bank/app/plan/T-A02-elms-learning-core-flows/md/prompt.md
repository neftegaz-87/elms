## Epic

### Outcome

Развернуть в модуле LMS платформы ELMS полноценный учебный контур (Core Learning Flows) на Frappe Framework: потоки и группы (`ELMS Batch`), зачисления и слушатели (`ELMS Enrollment`), корпоративные подписки и квоты мест (`ELMS Subscription`), трекинг активности и времени изучения (`ELMS User Activity`, `ELMS Video Watch Log`), детальный прогресс по курсам и темам (`ELMS Course Progress`, `ELMS Lesson Progress`), а также обновить навигацию и карточки Workspace «LMS» в Desk с учётом требований законодательства РФ (ФИС ФРДО Рособрнадзора, Постановление Правительства № 2464 по охране труда, 152-ФЗ и Реестр ПО Минцифры № 1236).

### In

- Определение и регистрация доменных DocTypes в модуле `LMS`:
  - `ELMS Batch` (Учебный поток / Группа)
  - `ELMS Subscription` (Корпоративная подписка / Квота мест)
  - `ELMS Enrollment` (Зачисление слушателя на курс / в поток)
  - `ELMS Course Progress` (Сводный прогресс по курсу с допуском к экзамену)
  - `ELMS Lesson Progress` (Прогресс освоения конкретного урока и затраченное время)
  - `ELMS User Activity` (Журнал активности, сессий и телеметрии)
  - `ELMS Video Watch Log` (Журнал подтвержденного просмотра видеоматериалов)
- Обновление конфигурации рабочего пространства Workspace `LMS` в `elms/elms/desk/workspaces.py`:
  - Карточка «Управление обучением»: `ELMS Batch`, `ELMS Subscription`, `ELMS Enrollment`
  - Карточка «Успеваемость и прогресс»: `ELMS Course Progress`, `ELMS Lesson Progress`, `ELMS User Activity`
  - Карточка «Аттестация и документы»: `ELMS LMS Section`
- Сервисный уровень и Frappe Whitelist API для:
  - Зачисления слушателя в поток с проверкой квоты подписки (`elms.lms.api.enroll_learner`)
  - Фиксации активности и прогресса урока (`elms.lms.api.record_lesson_progress`, `elms.lms.api.heartbeat_video`)
  - Расчёта сводного прогресса курса и допуска к итоговой аттестации (`elms.lms.api.calculate_course_progress`)
- Матрица прав доступа DocPerm:
  - `ELMS Admin`: полный доступ RWCD
  - `ELMS LMS User`: чтение своих зачислений и запись своего прогресса/активности
  - `ELMS Operations User`: чтение подписок и потоков для взаимодействия с заказчиками
- Соблюдение нормативных ограничений РФ:
  - Хранение всех данных в локальной MariaDB (152-ФЗ)
  - Изоляция персональных данных между организациями
  - Фиксация времени изучения по Приказу Минобрнауки № 816
  - Готовность структур к экспорту в ФИС ФРДО и ЕИСОТ Минтруда РФ (ПП № 2464)
- Автоматизированные тесты (FrappeTestCase / pytest):
  - Unit/Behavior тесты DocTypes, жизненного цикла зачислений и квот
  - Тесты валидации и расчёта прогресса
  - Тесты прав доступа DocPerm (Fail-closed)
  - Проверка обновления структуры Workspace LMS

### Out

- Полный WYSIWYG конструктор уроков (выносится в следующий шаг редактора контента)
- Прямой эквайринг банковскими картами физлиц (B2B расчеты по договорам и счетам в Operations)
- Мобильные приложения iOS/Android
- Зарубежные видеохостинги (YouTube/Vimeo) без возможности локального проигрывания

### Done when

1. Все объявленные DocTypes зарегистрированы в модуле `LMS`, установлены через миграции и валидируются Frappe Framework.
2. В Desk Workspace «LMS» отображаются карточки «Управление обучением», «Успеваемость и прогресс», ссылки и быстрые переходы.
3. API `enroll_learner` корректно зачисляет слушателя в поток, списывает квоту подписки и создает документ `ELMS Course Progress`.
4. API `record_lesson_progress` обновляет статус урока, суммирует секунды активности и пересчитывает общий процент прохождения.
5. При достижении 100% рубежей проставляется признак `exam_eligible=1`.
6. Права `DocPerm` защищают данные: слушатель не видит чужие зачисления, гость не имеет доступа к API (fail-closed).
7. Полный тестовый набор проходит без регрессий.

### Forbidden after

- Доступ гостя к данным слушателей.
- Ручная накрутка прогресса без фиксации времени активности.
- Превышение лимита мест по корпоративной подписке без ошибки валидации.
- Зависимость от внешних незащищенных CDN.
