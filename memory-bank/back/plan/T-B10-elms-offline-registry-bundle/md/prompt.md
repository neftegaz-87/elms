## Epic

### Outcome
ELMS можно поставить и поднять в изолированном контуре без интернета: готовый комплект образов, явный офлайн-профиль без Vault в составе продукта, проверка air-gap и перечень лицензий. Онлайн-поставка с Vault при этом не ломается и не получает тихих обходов.

### In
- Офлайн-бандл pin'нутых образов приложения и runtime-среды (без Vault)
- Отдельный профиль секретов файлами для офлайн-установки
- Скрипты упаковки/установки и доказательство работы без внешней сети
- SBOM/лицензии и краткая русская инструкция поставки

### Out
- Подача заявления в реестр Минцифры и юридический пакет правообладателя
- Сертификация на Astra/РЕД и зеркало исходников в РФ
- Замена Vault другим движком и учебный LMS-функционал
- Один контейнер «со всей инфраструктурой»

### Done when
1. На хосте без доступа наружу бандл загружается и поднимает полный прикладной граф без сервисов Vault.
2. Попытка офлайн-установки без образов, без файла секретов или с Vault внутри бандла завершается ошибкой, а не «успехом через pull/CDN».
3. Connected-prod путь с Vault не переключён на тихий `.env`-fallback.

### Forbidden after
Два способа секретов в одном профиле · pull во время офлайн-install · Vault в составе офлайн-продукта «на всякий случай» · инструкции «докачайте из интернета» для изолированного контура

### Chat decisions
- Цель эпика — техническая air-gap способность + SBOM, не юр. подача
- Vault вне продукта и вне офлайн-бандла
- Доказательство на Ubuntu/Debian; Astra/РЕД позже
- Секреты офлайн — отдельный file profile; online Vault сохраняется
- В бандл входит полный prod-граф минус Vault/Vault-Agent

## Board

title: Офлайн-поставка ELMS без интернета

summary: |
  Готовим комплект установки учебной платформы, который можно развернуть на сервере без доступа в интернет: образы уже внутри набора, установка не качает ничего снаружи.

  Зачем это бизнесу
  Для учебного центра и будущей регистрации в реестре отечественного ПО критично уметь работать в закрытом контуре. Иначе поставка зависит от внешних реестров образов, а экспертиза может отказать. Отдельно убираем спорный компонент секретов из состава продукта в офлайн-комплекте, чтобы не тащить лицензионный риск в «коробку» ELMS.

  Технически
  1) Профиль compose без Vault и без docker pull (только digest-образы)
  2) Секреты для офлайн — заранее подготовленные файлы; онлайн-контур с Vault не ломаем
  3) Скрипты упаковки и установки, проверка air-gap, SBOM и краткая инструкция на русском
  Результат для наблюдателя: один версионированный офлайн-бандл и отчёт, что система поднялась без внешней сети.
