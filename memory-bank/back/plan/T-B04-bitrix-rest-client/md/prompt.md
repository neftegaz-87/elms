## Epic

### Outcome
Оператор интеграции по одному секрету входящего вебхука вызывает методы портала Bitrix24 и видит ответ целиком. Кривая настройка и ошибка портала заканчиваются явной причиной, а не пустым успехом.

### In
- Вызов произвольного метода и просмотр выданных прав
- Инструкция, как завести входящий вебхук и куда положить URL
- Отказ работать, если своей настройки нет

### Out
- Зеркало данных портала в системе
- Каталог обёрток по разделам портала
- Вход через приложение OAuth, события и исходящие вебхуки
- Доска и её секрет

### Done when
1. Команда вызова печатает JSON портала, когда вебхук и метод приняты.
2. Команда прав показывает, что вебхуку выдано, и по отдельному флагу — какие права на портале есть вообще.
3. Без своей настройки команда завершается ошибкой и не берёт секрет доски.
4. Ошибка портала не выглядит как успешный пустой ответ.

### Forbidden after
Второй клиент на ту же роль. Подстановка секрета доски, если своя настройка пуста. Разбор ответа регулярным выражением из текста страницы. Тихий повтор при лимите. Режим, который молча выкидывает методы изменения данных.

### Chat decisions
- Форма работы — универсальный вызов любого метода и отдельный просмотр прав, не выгрузка сущностей и не набор модульных обёрток.
- Секрет интеграций — новый входящий вебхук в своей настройке. Секрет доски не используется.
- Методы изменения данных разрешены тем же вызовом: отдельного режима «только чтение» нет.
- Список прав в коде не зашит. Его задают при создании вебхука, команда показывает факт.

## Board

title: Скрипты вызова API Битрикс24

summary: |
  Что делаем
  Две команды: одна вызывает любой метод REST портала и показывает ответ, вторая показывает, какие права есть у вебхука.
  Зачем
  Чтобы интеграции ходили в Битрикс одним способом и было видно, что портал ответил и каких прав не хватает.
  Стадии
  1) Настройка URL вебхука с явной ошибкой, если его нет
  2) Команда вызова метода
  3) Команда просмотра прав
  4) Инструкция, как создать входящий вебхук и куда вставить адрес
  Результат для наблюдателя
  По инструкции можно завести вебхук, вписать адрес в настройки и получить JSON от портала. Чужой адрес доски эти команды не подхватывают.
