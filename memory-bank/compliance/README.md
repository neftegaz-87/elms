 # Нормативные требования и сертификационные правила
 
 Регуляторные требования государственных органов РФ, стандарты сертификации и правила взаимодействия с государственными информационными системами, обязательные для архитектуры, данных и бизнес-процессов платформы ELMS.
 
 ## Реестр нормативных спецификаций
 
 | Документ | Регулятор / Основание | Область действия |

 | [reestr-po-certification.md](reestr-po-certification.md) | **Минцифры РФ**, Постановление Правительства РФ № 1236 | Включение в Реестр российского ПО: автономность, отказ от зарубежных облаков/CDN, запрет GPL/AGPL, сборка в РФ, поддержка отечественных ОС. |
 | [fis-frdo-export.md](fis-frdo-export.md) | **Рособрнадзор**, ФИС ФРДО | Государственная выгрузка сведений о выданных документах: шаблоны ДПО (40 колонок) и ПО (35 колонок), файлы `ОГРН-КПП-год-номер.xlsx`, УКЭП, снимки выдачи, дубликаты. |

 | [152-fz-privacy.md](152-fz-privacy.md) | **Роскомнадзор**, 152-ФЗ «О персональных данных» | Локализация серверов и баз данных в РФ, разделение бессрочных реестров и телеметрии, запрет утечки ПДн во внешние зарубежные сервисы. |
